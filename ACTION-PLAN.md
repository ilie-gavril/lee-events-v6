# Lee Events — acțiuni SEO

1. **Publică sitemapul actualizat.** Verifică după publicare că `https://lee-events.ro/sitemap.xml` include toate cele nouă URL-uri WebP. Păstrează lista sincronizată când înlocuiești fotografiile din galerie.
2. **Verifică indexarea în Search Console.** Trimite sitemapul dacă nu este deja înregistrat și verifică URL-ul canonic prin Inspectarea adresei URL. Consultă canonicalul selectat de Google și starea de indexare. [Ghidul Google pentru canonicalizare](https://developers.google.com/search/docs/crawling-indexing/canonicalization-troubleshooting)
3. **Verifică performanța pe mobil și desktop.** Rulează PageSpeed Insights când serviciul este disponibil. Urmărește separat datele de laborator și datele de la utilizatori, dacă acestea sunt disponibile.
